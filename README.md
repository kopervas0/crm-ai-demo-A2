# CRM · Разделы «Воронка сделок» и «Клиенты» — тестовый проект

Демо-разделы внутренней CRM (по мотивам вакансии **AI CRM Developer, A2**):
Kanban-воронка со сделками, отдельный раздел клиентов со связанными
сделками, конструктор пользовательских полей, фильтрация, базовая
аналитика и черновая ролевая модель (менеджер / администратор).

## Стек

Фронтенд — чистые **HTML / CSS / JavaScript** без фреймворков и сборки.
Бэкенд — **Python на стандартной библиотеке** (без зависимостей): REST API +
SQLite. Оба слоя запускаются одной командой.

**Фронтенд:**
- `index.html` — разметка (шапка с вкладками, оба раздела, модалки)
- `css/styles.css` — вёрстка, светлая/тёмная тема через `prefers-color-scheme`
- `js/app.js` — логика: переключение вкладок, drag-and-drop, фильтры, CRUD сделок и клиентов, конструктор полей. Данные читаются/пишутся через REST (`fetch('/api/...')`)

**Бэкенд (`ai-crm-backend/`):**
- `src/api.py` — REST API (`/api/deals`, `/api/clients`) + раздаёт фронтенд как статику; хранилище SQLite
- `src/db.py`, `src/ai.py` — модель данных и речевая аналитика под «вторую фазу» (звонки, транскрибация, авто-задачи). Подробности — в `ai-crm-backend/README.md`

Сделки, клиенты и определения пользовательских полей теперь живут в **SQLite
на бэкенде** — изменения переживают перезагрузку и видны из любого браузера
(в отличие от прежнего localStorage).

## Что реализовано (по пунктам вакансии)

| Требование из вакансии              | Как показано в демо                                   |
|--------------------------------------|--------------------------------------------------------|
| Kanban-воронки                       | 6 колонок-этапов, drag-and-drop между ними             |
| Карточки клиентов и сделок           | Карточка сделки на доске + отдельный раздел «Клиенты» со своими карточками и модалкой, где видны все сделки клиента |
| Конструктор пользовательских полей   | Кнопка «Конструктор полей» — добавление/удаление полей, появляются в карточке |
| Фильтрация и базовая аналитика       | Поиск, фильтр по менеджеру/источнику/просрочке, панель статистики |
| Пользователи, роли и права доступа   | Переключатель роли (менеджер/админ) скрывает/показывает конструктор полей — задел под RBAC |
| REST API для интеграций              | Реальный REST-бэкенд (`/api/deals`, `/api/clients`) на Python + SQLite; фронтенд полностью работает через `fetch` |

## Как запустить

Одна команда поднимает и API, и фронтенд (нужен только Python 3):

```bash
python ai-crm-backend/src/api.py
```

затем открыть `http://localhost:8080`. При первом запуске база наполняется
демо-данными из `data/*.json`.

### REST API

| Метод и путь            | Действие                    |
|-------------------------|-----------------------------|
| `GET /api/deals`        | список сделок               |
| `POST /api/deals`       | создать сделку              |
| `PUT /api/deals/{id}`   | обновить сделку             |
| `DELETE /api/deals/{id}`| удалить сделку              |

Те же четыре метода — для `/api/clients` и `/api/fields` (определения
пользовательских полей конструктора).
